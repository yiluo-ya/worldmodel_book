# 第 4 章　训练细节：那些决定成败的小事

## 4.1 为什么单列一章

世界模型的论文里，方法往往只有半页，剩下的全是"实现细节"。这不是凑篇幅：
**同样的结构，训练细节没调对，开环误差能差一个数量级以上。**
本章把 exp03 的对比拆开，逐项说明每个技巧为什么有效。

## 4.2 残差预测

$$s_{t+1} = s_t + f_\theta(s_t, a_t)$$

而不是 $s_{t+1} = f_\theta(s_t,a_t)$。

**为什么**：dt = 0.01 s 时，状态的变化量比状态本身小 1-2 个数量级
（exp01：cartpole 一步变化 RMS = 0.063，而 $\dot\theta$ 能到 8 rad/s）。
网络如果直接回归 $s'$，它必须先用大部分容量"复述"输入，再叠加一个小量。
这既浪费容量，又让损失函数被大分量的维度主导。

**代价**：模型无法预测"跳变"（碰撞、接触切换）。这类系统需要事件检测或
混合专家（见 ch16）。

## 4.3 输入输出标准化

```python
sx = (S - S.mean(0)) / (S.std(0) + 1e-8)
```
三个地方都要做，而且**推理时必须用训练集的统计量**（这是最经典的部署事故：
用测试集的 mean/std，或者干脆忘了反标准化）。

exp06 里有个反向的例子：像素世界模型的线性版本用了 `ridge=1e-3` 时
单步 RMSE 是 0.64，改成 `ridge=100` 后是 0.033——因为 2304 维特征 vs
2000 样本是欠定问题，正则强度必须跟上维度。标准化的道理一样：**让每个
维度对损失贡献相当**。

## 4.4 输入噪声：最划算的一招

exp03 的核心数字（cartpole，dt=0.01，100 步开环归一化误差）：

| 数据覆盖 | 不加噪声 | 加 0.005 噪声 | 加 0.05 噪声 |
|---|---|---|---|
| 宽（杆会翻转） | 0.580 | **0.495** | 1.079 |
| 窄（温和小动作） | 4.580 | **0.968** | 1.475 |

两个观察，都很重要：

1. **噪声最优值很小**（0.005 倍状态标准差），比许多教程里的 0.05 小一个
   数量级。加太多时模型会学会"忽略输入里的小差异"，而小差异恰恰是动力学。
2. **收益取决于数据覆盖**：窄覆盖从 4.58 降到 0.97（4.7 倍），
   宽覆盖只从 0.58 降到 0.50（1.2 倍）。

**机理**（三点，缺一不可）：

1. **数据增强等于告诉模型"附近的状态也要预测对"**。真实的动力学是局部
   光滑的，所以这是正确先验。
2. **rollout 时状态必然偏离训练轨迹**。把噪声加在输入上，等于在训练期
   就模拟了"输入略微跑偏"的情形。
3. **它同时是正则化**：逼网络学一个 Lipschitz 有界的函数，抑制了外推区
   的"疯狂输出"。

**噪声幅度怎么选**：从**状态标准差的 0.5%（0.005）**起步，向上扫到 0.02。
超过 0.05 基本都有害（exp03 的 `exp03_noise_scan.png` 画了整条曲线）。

## 4.5 激活函数

推荐 `tanh` 或 `silu`，理由不是"更先进"，而是**二阶导存在**：

- 物理动力学 $f(s,a)$ 是光滑的，rollout 里每一步都在同一条光滑流形上走。
  ReLU 的折线会在 rollout 中把误差变成阶梯状，且外推区是线性外延（可能
  非常陡）。
- 对规划（ch08）而言更致命：CEM/梯度规划要在模型上求导或采样，
  非光滑模型的优化景观是碎的。

## 4.6 损失函数：MSE 够用吗

实践中用 MSE 就够，但要知道它的两个偏差：

1. **MSE 对应高斯似然**，它假设误差各维同方差。真实系统里位置误差和
   速度误差量级不同（标准化后缓解）。
2. **MSE 在"不确定的地方"会输出均值**。这是生成式世界模型"变糊"的根源：
   如果多个未来都合理，MSE 最优解是它们的平均，而平均值往往不是任何
   一个合理的未来（exp06 的 `freeze` 模型就是极端例子，见 ch12）。

改进方向（本书不实现，但要知道存在）：

- 多模态损失：混合高斯（MDN）、分位数、扩散/流匹配
- 多步损失：直接训练 $k$ 步预测（见 ch5 §5.6）
- 感知损失：像素模型用 VGG/对比学习特征而不是原始像素差（ch12）

## 4.7 训练时长与过拟合

判据不是 train/val 曲线，而是**开环误差**。经验：

- 先训到 val 不再下降，再往前训 1.3 倍 epoch，通常会继续改善开环
  （因为开环更依赖"外推行为"而不是拟合精度）。
- 如果加噪声后 val 一直很高、但开环已经不错，别急着停：那是噪声项本身的
  贡献，不代表欠拟合。

## 4.8 一个完整的训练模板（可抄）

```python
class WorldModel:
    def fit(self, S, A, SN, epochs=40, noise=0.05, aug=3, lr=3e-3):
        # 1) 残差目标
        dS = SN - S
        # 2) 标准化（三组统计量都要存下来）
        self.sx, self.su, self.sy = Stats(S), Stats(A), Stats(dS)
        # 3) 噪声增强
        S, A, SN = augment(S, A, SN, noise, aug)
        # 4) 训练
        for ep in range(epochs):
            for mb in batches(concat(self.sx(S), self.su(A)), self.sy(dS)):
                loss = mse(net(mb.x), mb.y)
                adam_update(loss)
```

配三个必须一起保存的东西：网络参数、**三个标准化器的统计量**、以及
训练时用的 dt（否则部署时时间尺度对不上，见 ch16 的失败案例）。

## 4.9 实验读数：为什么这些细节值得一章

把 exp03 的两组数字放在一起看（100 步开环归一化误差，好覆盖 vs 差覆盖）：

```
                  宽覆盖      窄覆盖
linear            0.912      1.630    ← 稳定地不准，但不会炸
mlp-plain         0.580      4.580    ← 数据差时炸出去
mlp-robust(0.005) 0.495      0.968    ← 两边都稳
```

读法：

1. **同样是那个 6000 参数的网络，在宽覆盖下它比线性模型好，
   在窄覆盖下它比线性模型差 2.8 倍。** 决定成败的不是参数多少，
   是数据覆盖与使用分布的差距。
2. **加噪声几乎免费地消除了这个风险**（窄覆盖 4.58 → 0.97）。
3. 线性模型的“稳”是另一种东西：它的外推是线性外延，不会爆炸，
   但也永远停在 0.9-1.6（差不多等于瞎猜水平）。

这就是世界模型工程的真相：**先让模型在分布外别乱来，再谈精度。**

## 4.10 练习

1. 把噪声从"加在状态上"改成"加在动作上"，开环误差会怎样？为什么？
   （提示：动作噪声等同于让模型学一个更宽的转移核）
2. 实现"多步损失"：不只预测 $t+1$，还预测 $t+2, t+4$（自回归展开 k 步
   后一起回传梯度）。在 cartpole 上它能替代噪声增强吗？
3. `save_mlp` 存了三个标准化器。故意不存 `sy`（输出标准化），重新加载后
   跑 rollout，看误差变成多少。这就是"部署事故"的复现。
