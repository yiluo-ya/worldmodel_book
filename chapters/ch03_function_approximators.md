# 第 3 章　函数逼近器：从线性到神经网络

## 3.1 一个思想实验

假设你不知道任何物理，只知道有一堆 `(s, a, s')` 的表格。要拟合
$s' - s$ 作为 $(s,a)$ 的函数，你需要选一族函数。这一章就把这族函数从
最简到最复杂过一遍，并用实验告诉你**什么时候该往上加复杂度**。

## 3.2 模型族一览

| 家族 | 参数量（cartpole） | 优点 | 缺点 | 何时用 |
|---|---|---|---|---|
| 线性 + 最小二乘 | 15 | 秒训、可解析、外推行为可预测 | 拟合能力有限 | 基线、诊断、数据少 |
| 线性 + 二次特征 | 60 | 能抓非线性 | 手工特征 | 低维、物理近似 |
| 局部线性 (LWR) | 数据量级 | 局部准 | 查询慢 | 数据密集区 |
| 高斯过程 | 数据量级 | 自带不确定度 | O(n³) | 低维、小数据 |
| MLP | 6k-50k | 拟合强、推理快 | 外推失控、需调参 | 主力 |
| 图网络 (GNN) | 结构相关 | 天然多体、可变拓扑 | 实现复杂 | 多刚体/多机器人 |
| Transformer | 大 | 长历史、多模态 | 贵、数据饥渴 | 视频/大规模 |
| 能量/哈密顿网络 | 小 | 长期守恒 | 需结构化状态 | 物理已知 |

## 3.3 训练一个 MLP 世界模型的骨架

伪代码，也是本书 `wm_nn.MLPModel` 的全部内容：

```python
# 数据: S (N,d), A (N,m), S_next (N,d)
dS = S_next - S
# 1) 标准化（关键）
sx, su, sy = Standardizer().fit(S), Standardizer().fit(A), Standardizer().fit(dS)
X = concat(sx(S), su(A))          # (N, d+m)
Y = sy(dS)                        # (N, d)
# 2) 拟合一个 MLP: Y ≈ net(X)
for epoch in range(E):
    for batch in shuffle(X):
        err = net(batch.X) - batch.Y
        update(net, grad(err))
# 3) 推理时别忘了标准化
def predict(s, a):
    return s + sy.inv(net(concat(sx(s), su(a))))
```

四个设计决定，每一个都不是随便选的：

1. **预测残差 $\Delta s$ 而不是 $s'$**：见 ch02 §2.3。
2. **输入输出都标准化**：状态里 `x`（±0.5 m）和 `θ̇`（±8 rad/s）量级差
   16 倍。不标准化时，网络会把容量全花在拟合大分量的那几维上。
3. **tanh 而不是 ReLU**：动力学是光滑的，`tanh` 的二阶导存在；
   ReLU 的折线边界会让 rollout 里的误差变成"阶梯"，而且外推区全是线性外延。
4. **Adam + 小学习率**：这个没什么可辩的，3e-3 起步。

## 3.4 一次“失败”：数据覆盖比模型容量更决定命运

这一节本来想讲一个漂亮的反直觉结论："神经网络单步最好，开环最差"。
但把数据换成更宽的覆盖后，**那个结论就倒了**。这个“倒了”比原结论更有教益，
所以把两个结果都摆出来。

exp03 用同一份代码、同一个网络，只改数据覆盖：

- **宽覆盖**：随机控制在 ±30 N 里猛推，杆会转好几圈（$|\theta|_{\max}=10.2$ rad）
- **窄覆盖**：初始状态很小、动作只有 1/6（$|\theta|_{\max}=6.1$ rad）

两种覆盖下，三个模型的 100 步（1 s）开环误差：

| 数据集 | linear | mlp-plain | mlp-robust（噪声 0.005） |
|---|---|---|---|
| 宽覆盖 | 0.912 | **0.580** | **0.495** |
| 窄覆盖 | 1.630 | **4.580** | **0.968** |

两个世界、同一套代码，结论完全相反：

- **宽覆盖下**：mlp-plain 已经很好（0.58），加噪声只再降 15%。
  神经网络自己就学会了泛化，因为数据里已经有“各种奇怪状态”。
- **窄覆盖下**：mlp-plain 冲到 **4.58**（完全失效），而加噪声的版本
  只用 1.0，**改善了 4.7 倍**。

> 所以“神经网络在开环里崩坏”**不是必然**。它取决于一件事：
> **使用时的状态分布，离训练数据有多远。**
> 噪声增强补的正是这个差距。

### 为什么窄数据会崩

rollout 时，模型第 $h$ 步的输入是它自己第 $h-1$ 步的输出。第一步的小偏差
把状态推到训练集边缘，第二步偏差更大，第三步就到了"网站在这里随便乱说"
的区域。而神经网络在训练分布外的行为是**任意的**——它可能输出一个巨大
的增量，直接把状态炸飞。

线性模型也有外推问题，但它的外推至少是**线性外延**，行为温和（0.912 / 1.630），
所以它反而不会炸，只是“稳定地不准”。

### 噪声到底加多少

exp03 扫了五档（噪声 = 状态标准差的倍数），这是本章最实用的一张表：

| 噪声倍率 | 宽覆盖 h=100 | 窄覆盖 h=100 |
|---|---|---|
| 0（不加） | 0.580 | **4.580** |
| **0.005** | **0.495** | **0.968** |
| 0.01 | 0.576 | 1.235 |
| 0.02 | 0.757 | 1.425 |
| 0.05 | 1.079 | 1.475 |

三条可以直接抄走的结论：

1. **最优噪声很小**：0.005（即 0.5%），比很多教程里的 0.05 小一个数量级。
   噪声太大时，模型学会了“忽略输入里的小差异”——而那些小差异
   正是动力学本身。
2. **两种覆盖的最优点相同**（都是 0.005），说明这个值是“动力学光滑性”
   决定的，不是数据量决定的。
3. **收益大小取决于覆盖**：窄覆盖 4.7 倍，宽覆盖只有 1.2 倍。
   所以噪声增强是“保险”，不是“万灵药”：数据覆盖好时它只是小补贴。

> **工程结论**：训世界模型时加上输入噪声，幅度从 0.005 倍状态标准差
> 开始扫。但要记住：**它的作用是弥补覆盖不足，不是替代采集。**

## 3.5 数据量 vs 复杂度：没有免费的容量

exp03 的另一张表（宽覆盖数据，50 步开环归一化误差，训练集从 1275 到 25500）：

| 训练样本 | linear | mlp-robust |
|---|---|---|
| 1275 | 0.732 | **0.700** |
| 2550 | 0.740 | **0.567** |
| 5100 | 0.740 | **0.478** |
| 10200 | 0.730 | **0.479** |
| 17850 | 0.729 | **0.450** |
| 25500 | 0.733 | **0.410** |

读法：

1. 线性模型的曲线**从头到尾都是平的**（0.729-0.740）。它已经饱和了——
   数据再多也不会更好，因为它缺的是表达能力，不是数据。
2. MLP **在最小数据量（1275）时就略优于线性**（0.700 vs 0.732），
   并且随数据量单调改善到 0.410。
3. 这和“小数据时线性更好”的教科书直觉不一致。原因在于任务：
   宽覆盖数据里杆会翻转，线性模型根本无法表达 $\sin\theta$ 的来回变号，
   而 MLP 能。**如果任务本身就非线性，“用线性模型更稳”不成立。**

工程判断（修正版）：

> 先看任务有多非线性。近似线性的任务：小数据用线性/高斯过程。
> 明显非线性的任务（翻转、接触、大角度）：MLP 从头就值得试，
> 参数少一点（几千）就不怕小数据。

## 3.6 训练曲线怎么读

exp03 的 `mlp-robust` 训练过程（宽覆盖数据，噪声 0.005）：

```
train_rmse 从 0.63 一路降到 0.34 附近
val_rmse   从 0.57 降到 0.32 附近
```

train 略高于 val，因为 train 的输入被噪声污染过（val 没有）。

但要注意：**在世界模型里，train/val 的绝对差距不是主要矛盾**，
因为真正的差距在"rollout 分布"上，而 val 集也是单步的。

这是初学者最容易搞错的一点：

> 世界模型的训练集、验证集、测试集，全都是"单步"的。
> 但它的实际用途是"多步"。所以 train/val 曲线再漂亮，也不能预测开环表现。

ch12 会给出一套正确的评价方法。
