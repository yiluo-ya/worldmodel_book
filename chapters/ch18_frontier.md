# 第 18 章　前沿、争议与学习路线

## 18.1 现在的共识与争议

### 已经比较共识的

1. **世界模型的评价必须按视界报告**（ch5、ch12）。
2. **单步精度不预测闭环性能**（ch3、ch8、exp10）。
3. **输入噪声增强几乎免费且有效**（ch4）。
4. **规划需要不确定性**（ch6）。
5. **纯黑箱在长期、分布外不可靠**（ch7、ch13）。

### 还在激烈争论的

**争议一：要不要学像素？**

- 一派（生成式）：学出完整观测才能做通用任务、才有"理解"
- 一派（latent/无重构）：像素细节与决策无关，学它浪费容量
- 中间派：多尺度，低层学像素、高层学抽象

我的判断：**取决于任务是否需要"生成"能力**。做控制，不需要；做内容，
必须要。

**争议二：世界模型 vs 直接从数据学策略（model-free）**

- model-free 派：模仿学习（BC、Diffusion Policy）已经在很多任务上很强，
  世界模型多了一层误差源
- 世界模型派：数据效率是硬优势，尤其在有真实交互成本时

我的判断：**在数据便宜（仿真、互联网视频）时 model-free 占优；
在数据昂贵（真机）时世界模型占优。**

**争议三：Transformer 会不会统一一切**

现在的视频世界模型基本都是 Transformer/扩散。但它有两个硬伤：
推理延迟（闭环控制要毫秒级）、长时误差累积（ch7）。所以短期内
在实时控制里，小 MLP / RNN 仍有不可替代的位置。

## 18.2 五个开放问题（值得做研究的）

1. **如何让模型"知道自己不知道"**——目前靠集成，代价是 K 倍推理。
   能不能训一个单模型自带可靠的不确定性？
2. **如何跨系统泛化**——现在的模型基本"一个系统一个模型"。
   能不能有"物理基础模型"（类似 LLM 的跨域能力）？
3. **如何处理接触**——接触是刚体动力学最难的间断点，而机器人任务
   几乎都是接触任务。目前的模型在接触瞬间误差会跳变。
4. **长时程怎么突破 Lyapunov 上限**——目前靠"价值函数"绕过去，
   但这不是真正的长时预测。有没有本质不同的方法（比如学到抽象层）？
5. **如何评价**——ch12 的指标体系还是手工的。能不能有一个
   "世界模型界的 ImageNet"？

## 18.4 必读论文（按难度排序）

**入门**
1. Ha & Schmidhuber, *World Models* (2018) — 概念起源，可视化极好
2. Chua et al., *PETS* (2018) — 集成 + MPC 的经典组合
3. Hafner et al., *DreamerV3* (2023) — 目前最完整的工程

**进阶**
4. Hafner et al., *PlaNet / Dreamer* (2019/2020) — RSSM 的来龙去脉
5. Hansen et al., *TD-MPC2* (2024) — 隐式模型 + 规划
6. Yu et al., *MOPO* (2020) — 不确定性惩罚的理论

**视野**
7. LeCun, *A Path Towards Autonomous Machine Intelligence* (2022)
   — JEPA 的世界观
8. Bruce et al., *Genie* (2024) — 交互式视频生成
9. Assran et al., *V-JEPA* (2024) — 不做重构的世界模型

**读论文的方法**：每篇只找三样东西——(a) 模型结构图，(b) 评价指标表，
(c) 失败案例分析。前两项 20 分钟能看完，(c) 往往在附录里，最值钱。

## 18.5 常见误解的最终清单

读到这里，回头看这十条，每一条本书都用实验反驳或确认过：

1. ❌ "世界模型就是仿真器" → 它只需要对任务够用（ch1）
2. ❌ "模型越大越准" → 容量买不回长时精度（ch3）
3. ❌ "单步误差小就能用" → exp03 的反例（ch3）
4. ❌ "训练 loss 下降就是好" → 开环曲线才是标准（ch5）
5. ❌ "模型在验证集上好就没问题" → 外推差 50 倍（ch6）
6. ❌ "有模型就能规划好" → 错的模型比随机更糟（ch8）
7. ❌ "在模型里优化策略能省一切" → 优化器会钻漏洞（ch9）
8. ❌ "像素误差小 = 世界模型好" → freeze 基线反例（ch10）
9. ❌ "预测越久越好" → 混沌有硬上限（ch7）
10. ❌ "世界模型可以替代物理" → 结构化先验仍然最强（ch13）

## 18.6 如果只记三句话

> **一、世界模型的价值 = 在这个模型里试错比在现实里试错便宜多少。**
> 所以评估它，永远要问"用来做什么"。

> **二、它一定会错，而且错的方式比错的量更重要。**
> 会说自己不知道的模型，比更准但嘴硬的模型有用。

> **三、能写成物理公式的地方，别用神经网络；**
> 不能用公式的地方，世界模型才有存在价值。

## 18.7 收尾：这本书想教会你的事

回到最开始的问题：怎么教一个白板理解世界模型？

答案不是"讲清楚一个公式"，而是让他在自己的手上摸到三件事：

1. **预测很难**（exp03 里同一个网络，4.58 与 0.58 的差距比任何文字都有说服力）
2. **误差会复利**（exp10 的视界扫描）
3. **模型的价值在于省下试错**（exp08 的账本）

如果这三件事你已经在自己的终端里亲眼看到过，那这本书的目的就达到了。
剩下的，都是这三件事的变体。
