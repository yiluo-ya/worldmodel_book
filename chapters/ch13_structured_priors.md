# 第 13 章　结构化先验：把物理塞进模型

## 13.1 一条被低估的路线

前十二章的路线是"黑箱"：给数据，让网络自己学。它简单、通用，但有一个
根本弱点：**每个新系统都要重新采数据、重新训练**。

另一条路线是"白盒/灰盒"：把已知的物理结构写进模型，只让数据去补未知的
部分。在机器人领域，这条路往往更实用，因为：

1. **数据效率高几个数量级**（牛顿方程不需要训练）
2. **外推行为可控**（物理公式在分布外的表现是合理的）
3. **可解释、可验证**（能量守恒可以直接检查）

## 13.2 本书自己就用了白盒模型

`wc_cartpole.py` 里的 `AnalyticCartPole` 是这样写的：

$$
\begin{aligned}
(m_c + m)\ddot x + m r\cos\theta\,\ddot\theta - m r\sin\theta\,\dot\theta^2 &= F - c_x\dot x\\
m r\cos\theta\,\ddot x + (I + mr^2)\ddot\theta - mgr\sin\theta &= -c_\theta\dot\theta
\end{aligned}
$$

参数全部从 MuJoCo 模型里读出来（质量、惯量、阻尼、杆长、重力），
用同一个 RK4 积分器推进。

**验证结果：与 MuJoCo 逐位一致**（200 步内的最大绝对偏差 0.0000）。
这不是巧合，因为 MuJoCo 求解的就是这组方程。

有了这个白盒模型：

- exp05 用它做"完美模型"的上界对照（立住，末段 |θ| = 0.075 rad）
- exp08 用它做"理想世界"里的策略优化（与真机 CEM 结果完全一致）
- exp10 用它演示"视界越长越好"（H=80 时代价 121）

**一个 30 行的解析模型，胜过一个 6000 参数的神经网络。**
这不是说神经网络没用，是说：**能用已知结构的地方，别用学习。**

## 13.3 三条路线的谱系

```
纯白盒            灰盒                    纯黑盒
物理公式    物理骨架 + 学残差/参数    端到端网络
    │                 │                    │
 零数据          少量数据              大量数据
 外推可控        外推较可控             外推失控
 建模成本高      折中                   通用
```

### 白盒：system identification

不是"没有学习"，而是**只学参数**。比如：

- 学每个连杆的质量、惯量、摩擦系数（十几个数）
- 用最小二乘法或可微仿真（MuJoCo MJX / Brax / DiffTaichi）反传梯度

优点：极少数据（几分钟的激励轨迹）；结果可解释；外推安全。
缺点：需要正确的模型结构（接触、柔性、液压都要单独建模）。

### 灰盒：物理骨架 + 学残差

$$
s_{t+1} = \underbrace{f_{\text{phys}}(s_t, a_t)}_{\text{已知}}
         + \underbrace{g_\theta(s_t, a_t)}_{\text{学}}
$$

残差网络只负责"物理没建模的部分"：接触、摩擦、气动、电机延迟。
这是机器人领域最实用的做法，也是很多商业化系统的核心。

关键技巧：**残差项要小**。如果 $g_\theta$ 的输出和 $f_{\text{phys}}$ 同量级，
说明物理模型根本不对，应该先修物理。

### 黑盒：本书前面所有内容

优点：不需要建模知识；能处理"物理说不清"的系统（人、软体、流体）。
缺点：数据饥渴；外推不可控；难验证。

## 13.4 结构化先验的四个层次

从上到下，侵入性递增：

| 层次 | 做法 | 例子 |
|---|---|---|
| ① 输入特征 | 手工构造物理量（速度、差分、能量） | exp09 的 finite-diff 把单步误差从 0.48 降到 0.14 |
| ② 输出约束 | 让网络输出满足某些恒等式 | 对称性、守恒量 |
| ③ 结构 | 网络架构反映物理连接（图网络、哈密顿网络） | 多刚体：节点=连杆，边=关节 |
| ④ 完整方程 | 直接写动力学，只学参数 | 本章的 `AnalyticCartPole` |

exp09 已经给了层次 ① 的实测：**同样的网络，只把"差分速度"塞进输入，
单步误差降 3.4 倍**。这是最便宜的结构化先验。

## 13.5 哈密顿/拉格朗日网络：一个值得知道的想法

普通网络学 $\dot s = f(s,a)$，不保证能量守恒。有一类工作改成学
**哈密顿量** $H(q,p)$，然后用力学方程生成动力学：

$$
\dot q = \frac{\partial H}{\partial p}, \qquad
\dot p = -\frac{\partial H}{\partial q} + F
$$

这样构造出的动力学**自动满足能量守恒**（在无外力时），因为
$\dot H = 0$ 是结构性的，不靠数据约束。

优点：长期 rollout 的能量漂移极小（对比 exp07 里模型 25% 的漂移）。
缺点：需要把状态拆成"广义坐标 + 广义动量"，很多系统不好拆（接触、
非保守力）。

这体现了"结构化先验"的一般原则：

> **把你希望模型满足的性质，写成结构，而不是写成损失项。**

写在损失里是"软约束"（模型可能违反）；写在结构里是"硬约束"（不可能违反）。

## 13.6 用探针验证结构

exp07 的能量探针给出了最清晰的对照：

| | 能量漂移（250 步内） |
|---|---|
| 真实轨迹（MuJoCo RK4） | 3.41e-08（严格守恒） |
| MLP 黑箱模型 | 25% |

一个黑箱模型可以做到单步 nRMSE 0.032，却在能量上错 25%。
**这说明它学的是"轨迹的统计规律"，不是"物理"。**

对很多任务这够用（短期预测、视觉演示），但对长时程、对安全关键系统
不够。这也是为什么"物理 + 学习"的混合路线在机器人里始终有市场。

## 13.7 什么时候该用哪条路线

| 场景 | 建议 |
|---|---|
| 刚体机器人、已知 CAD | 白盒 + 学参数（摩擦、延迟） |
| 有接触、有柔性 | 灰盒（物理骨架 + 残差） |
| 人、动物、流体、人群 | 黑盒 + 大量数据 |
| 需要长期预测（>10 s） | 必须有结构（否则误差不可控） |
| 需要快速原型 | 先黑盒跑通，再逐步加结构 |

一个实用的启发：

> 如果你的模型长期 rollout 后"物理上不可能"（能量暴涨、物体穿模、
> 动量不守恒），那它一定在某些下游任务上会失败——只是你还没测到。

## 13.8 练习

1. 用 `AnalyticCartPole` 的公式，手写一个"参数错误的"白盒模型
   （把杆质量乘 1.3），用它做 exp05 的 MPC。任务还能成吗？这说明
   白盒模型对参数误差有多敏感？
2. 实现灰盒：$\Delta s = f_{\text{phys}}(s,a) + g_\theta(s,a)$，
   其中 $f_{\text{phys}}$ 用错误参数的白盒模型。看 $g_\theta$ 能否
   自动补偿参数误差（提示：输出应该接近 $-\delta f$）。
3. 给 MLP 加一个"能量守恒损失"（惩罚 rollout 里 $E$ 的变化），
   看 exp07 的能量漂移能降到多少。它会影响 RMSE 吗？
