# 第 12 章　怎么评价一个世界模型

## 12.1 为什么这章要单独讲

模型评价是最容易被糊弄、也最容易自欺的环节。一个常见的悲剧：

> 训练集/验证集 RMSE 0.003，论文里写得漂亮，上机器人两天就摔。

原因是：**训练和评价都用单步，使用却是多步 + 闭环**。
本章给出一套可操作的指标体系。

## 12.2 六层指标（从便宜到贵）

| 层级 | 指标 | 回答什么问题 | 成本 |
|---|---|---|---|
| L0 | 单步 RMSE（归一化） | 拟合得好不好 | 秒级 |
| L1 | 开环误差-视界曲线 | 能预测多久 | 秒级 |
| L2 | 物理一致性探针 | 学到物理了吗 | 秒级 |
| L3 | 任务相关探针 | 对下游有用吗 | 分钟级 |
| L4 | 闭环表现 | 真能用吗 | 分钟-小时级 |
| L5 | 鲁棒性/分布外 | 换场景还行吗 | 小时级 |

**没有 L1 到 L5 的模型评价都不算数。** 下面逐层给方法。

## 12.3 L0：单步误差的正确算法

三个必须：

1. **归一化**。每维除以该维在训练集上的标准差，否则单位混在一起没意义。
2. **残差还是绝对值，说清楚**。本书用归一化的 $\Delta s$ 误差。
3. **按时间切分**。随机切分会让相邻样本分居训练/测试，等于泄漏未来。

```python
scale = S_train.std(0) + 1e-9
rmse = sqrt( mean( ((pred - S_next) / scale)**2 ) )
```

参考值（cartpole，dt=0.01，本书实验）：线性 0.11、MLP+噪声 0.06。
**如果你的单步误差 > 0.2，先别管别的，去调训练。**

## 12.4 L1：开环误差曲线（最重要的一张图）

```python
def rollout_errors(predict, S, A, SN, horizon, ep_len, scale):
    # 起点必须在 episode 内部：不能跨段
    starts = sample_episode_internal_starts(S, horizon, ep_len)
    err = zeros(horizon + 1)
    for st in starts:
        s = S[st]
        for h in range(horizon):
            s = predict(s, A[st + h])
            err[h+1] += rms((s - SN[st+h]) / scale)
    return err / len(starts)
```

必须报告的量（不只是画图）：

- $h=1$ 的误差（等价于 L0）
- **$\epsilon(h) < 0.1$ 的最大 $h$** ← 这是你的规划视界预算（ch16）
- **饱和值**（长时间后稳定在哪个水平，1.0 = 瞎猜）
- 达到 0.5 的 $h$

本书各模型的实测：

| 模型 | $h=1$ | $h=10$ | $h=100$ | 首次 >0.5 |
|---|---|---|---|---|
| linear (cartpole, 宽覆盖) | 0.030 | 0.116 | 0.912 | ~20 |
| mlp-plain (窄覆盖) | 0.003 | 0.012 | 4.580 | ~40 |
| mlp-robust (窄覆盖) | 0.002 | 0.009 | 0.968 | ~55 |
| mlp (双摆，混沌) | 0.032 | — | — | ~87 步 |

注意 mlp-plain 那行：$h=100$ 时 4.58，意味着状态已经飞出去了（比瞎猜还差 4 倍）。
这种模型
在 L0 上最好，在 L1 上最差——**L0 会骗你，L1 不会。**

## 12.5 L2：物理一致性探针

用领域知识做断言，而不是比 RMSE。

```python
# 能量守恒探针（来自 exp07）
E_true  = energy(真实轨迹)
E_model = energy(model.rollout(...))
drift = |E_model - E_model[0]| / |E_model[0]|
```

这类探针的价值：它们检查**全局结构**，而不是逐点误差。一个只会"复制
最近邻轨迹"的模型可以骗过 L1，但骗不过能量守恒。

可加的探针（按系统类型）：

| 探针 | 断言 | 实现成本 |
|---|---|---|
| 能量守恒 | $E(t) \approx E(0)$ | 低（解析公式） |
| 动量守恒 | $\sum m v = 0$（无外力） | 低 |
| 时间可逆性 | 反向动作应回到原状态（无耗散） | 中 |
| 对称性 | 旋转/平移输入 → 输出同步变换 | 中 |
| 静止不动 | $a=0$ 且无重力时状态不变 | 低（很能抓 bug） |
| 因果性 | 未来的 $a$ 不影响过去的 $s$ | 低 |

最后一条最容易漏，但对"用双向模型做世界模型"的论文是致命的。

## 12.6 L3：任务相关探针（本章的重点）

像素世界模型的困境（ch10）：**像素 RMSE 会奖励"什么都不预测"**。
解法：训一个"探针"（probe），把预测出来的东西解码成任务关心的物理量，
在物理量上量误差。

exp06 的实现（检索式探针，零训练）：

```python
class KNNProbe:
    def __init__(self, X_train, Y_train):
        self.bg = X_train.mean(0)
        Xn = normalize(X_train - self.bg)
        self.Xn, self.Y = Xn, Y_train
    def __call__(self, x):
        z = normalize(x - self.bg)
        return self.Y[(z @ self.Xn.T).argmax()]
```

结果（20 步开环）：

| 预测器 | 像素 RMSE | \|Δθ\| (rad) |
|---|---|---|
| freeze（不动） | **0.237**（最好） | 0.666（最差） |
| latent + clamp | 0.248 | 0.524 |
| latent | 0.276 | **0.519**（最好） |
| pixel-linear | 0.329 | 0.562 |

**排名颠倒**。这个对照实验本身就是最好的论据：任何世界模型论文如果只报
像素/重建误差，你都可以怀疑它藏了一个 `freeze`。

探针的其他形式：

- **线性探针**：latent → 物理量，用最小二乘。简单，但要求表征线性可解。
- **MLP 探针**：更灵活，但会掩盖表征的缺陷（MLP 自己能补一部分）。
- **规划探针**：用 latent 做 MPC，看任务成功率。最贵、最真。

推荐顺序：先用 KNN/线性探针（快，不易过拟合），再用规划探针验收。

## 12.7 L4：闭环表现

唯一真正的标准。三个必报量：

1. **任务成功率**（多次不同初值）
2. **代价/回报**（不只是"成功/失败"）
3. **失败模式**（摔了？抖了？卡住了？）

注意：闭环表现和 L1 不是单调关系。exp05 里 linear 的 L1 更好
（0.73 vs mlp 的 1.19 @100 步），但闭环里两者都失败，
而完美模型成功。**L1 是必要条件，不是充分条件。**

## 12.8 L5：鲁棒性与分布外

三类测试：

| 测试 | 做法 | 期望 |
|---|---|---|
| 初值外推 | 用训练范围外 1.5 倍的初始状态 | 误差上升但有界；σ 应显著上升 |
| 参数变化 | 改质量/摩擦 10-20% | 若有自适应则慢速恢复 |
| 扰动 | 加观测噪声、动作延迟 | 性能平滑下降，不是断崖 |

exp04 已经量过第一类：外推区误差是同分布区的 **36.4 倍**，
而集成的 σ 检测 OOD 的 AUC 是 **0.948**。

> 验收标准建议写成：
> "在训练分布外 1.5σ 的初值上，成功率不低于 XX%，且 σ 能标出 90% 的
> 外推样本。"
